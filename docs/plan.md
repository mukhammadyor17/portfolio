# ТЗ: Перенос портфолио turskhanov.dev на Vue 3

## Цель

Переписать существующий однофайловый сайт-портфолио (`portfolio.html`) на Vue 3 + TypeScript + Vite **без изменения дизайна, контента и поведения**. Результат должен быть пиксельно и функционально идентичен оригиналу, но с чистой компонентной архитектурой продакшен-уровня — репозиторий будет публичным и служит демонстрацией качества кода для работодателей.

Исходники истины: `portfolio.html` (эталон поведения и стилей) и `CLAUDE.md` (описание архитектуры). Оба файла лежат в корне. При любом расхождении между этим ТЗ и эталоном — спросить, не угадывать.

## Стек и требования к окружению

- Vue 3 (Composition API, `<script setup lang="ts">` во всех компонентах)
- TypeScript в strict-режиме, без `any`
- Vite, сборка в статику
- Стили: обычный CSS с CSS-переменными (scoped в компонентах + глобальный `variables.css` и `base.css`). **Без** Tailwind, препроцессоров и UI-библиотек
- Никаких зависимостей кроме vue. Исключение: dev-зависимости (typescript, vite, @vitejs/plugin-vue, vue-tsc)
- Google Fonts подключаются в `index.html` как сейчас
- Node 20+, менеджер пакетов npm

## Структура проекта

```
src/
├── main.ts
├── App.vue                  # переключение loader → site ↔ terminal
├── assets/
│   ├── variables.css        # все CSS-переменные из :root эталона
│   └── base.css             # reset, body, шрифты, .reveal, CRT-анимации
├── components/
│   ├── AppLoader.vue        # загрузочный экран, emit('done')
│   ├── site/
│   │   ├── SiteHeader.vue   # шапка с blur и кнопкой terminal
│   │   ├── HeroSection.vue  # хиро с печатающейся машинкой
│   │   ├── ProjectsSection.vue
│   │   ├── SkillsSection.vue
│   │   ├── ContactSection.vue
│   │   ├── BentoCard.vue    # базовая карточка (props: span, dark)
│   │   ├── SkillBar.vue     # props: name, percent, learning
│   │   ├── LearnRing.vue    # кольцо прогресса NestJS
│   │   └── TermCard.vue     # тёмная карточка-вход в терминал
│   └── terminal/
│       ├── TheTerminal.vue  # каркас: head, body, chips, prompt
│       ├── TermOutput.vue   # рендер строк вывода
│       └── MatrixCanvas.vue # canvas-дождь, самоочистка в onUnmounted
├── composables/
│   ├── useTypewriter.ts     # машинка: phrases, скорости, reduced-motion
│   ├── useReveal.ts         # IntersectionObserver для .reveal и баров
│   ├── useTerminal.ts       # состояние: история, вывод, run(), команды
│   ├── useTheme.ts          # темы терминала + persistence
│   └── useReducedMotion.ts  # одна точка чтения prefers-reduced-motion
├── data/
│   ├── profile.ts           # имя, роль, стек, контакты, фразы машинки
│   ├── projects.ts          # проекты (используются и сайтом, и терминалом)
│   ├── skills.ts            # навыки (используются и сайтом, и терминалом)
│   └── themes.ts            # 6 тем терминала
└── terminal/
    ├── commands.ts          # реестр команд
    ├── filesystem.ts        # фейковая ФС для ls/cat
    └── ascii.ts             # ASCII-арт MT, neofetch-шаблон
```

Ключевой принцип: **контент только в `data/`**. Навыки, проекты и контакты сейчас дублируются в HTML и JS эталона — в Vue-версии каждый факт живёт в одном месте, компоненты и команды терминала читают из общих модулей. Это исправление известного недостатка оригинала, оно обязательно.

## Функциональные требования

### 1. Загрузочный экран (AppLoader)

Как в эталоне: ASCII-логотип, посимвольная печать `turskhanov.dev`, построчное появление четырёх строк info, CRT-off, событие `done` → App показывает сайт. При `prefers-reduced-motion` — emit сразу, без анимации. Показывать при каждой загрузке (не сохранять факт показа).

### 2. Обычный режим

Все секции, бенто-сетка, анимации появления, каскад тегов, заполнение баров по скроллу, ховеры — 1:1 с эталоном. Адаптив: брейкпоинты 760px (бенто в колонку) и 640px (навигация, чипы терминала).

### 3. Переключение режимов

CRT-эффект выключения/включения (~450мс), реализовать через `<Transition>` с CSS-классами из эталона. Терминал держать смонтированным после первого открытия (`v-show`, не `v-if`) — чтобы история и вывод сохранялись при выходе и повторном входе, как в эталоне.

### 4. Терминал

- Все команды эталона: help, about, projects, skills, contact, neofetch, ls (-a, projects), cat, pwd, date, echo, history, theme, clear, exit, whoami, sudo hire-me, rm (-rf), git log, coffee, make coffee, matrix
- Все 7 пасхалок с точными текстами из эталона
- История по стрелкам, Tab-автодополнение, клик по фону — фокус в инпут
- Построчная печать вывода с задержкой 60мс (мгновенно при reduced-motion)
- Экранирование пользовательского ввода (перенести логику `esc`); вывод команд рендерить безопасно — если используется v-html, то только для доверенных шаблонов из `commands.ts`, никогда для сырого ввода
- Мобильные чипы-подсказки < 640px
- Реестр команд типизировать: `type Command = { run(arg: string | undefined, raw: string): CommandOutput; hidden?: boolean }` или аналогично — hidden-команды не попадают в help, но участвуют в автодополнении

### 5. Темы

6 тем из эталона. **Новое требование:** выбранная тема сохраняется в localStorage и восстанавливается при загрузке (ключ `terminal-theme`). Это единственное намеренное отличие поведения от эталона.

### 6. Matrix

Отдельный компонент, монтируется командой, очищает interval и canvas в `onUnmounted` и по завершении (~4.2с). Цвета — из текущей темы. При reduced-motion — только текстовый вывод.

## Нефункциональные требования

- `vue-tsc --noEmit` проходит без ошибок
- Никаких предупреждений Vue в консоли браузера
- Никаких утечек: повторное открытие/закрытие терминала и повторный запуск matrix не плодят таймеры и слушатели
- Доступность не хуже эталона: aria-метки, tabindex на TermCard, управление с клавиатуры
- Lighthouse (mobile): Performance и Accessibility ≥ 90
- README.md: скриншоты обоих режимов, список команд без спойлера пасхалок, `npm i && npm run dev`
- Обновить CLAUDE.md под новую структуру (разделы «Структура», «Соглашения», убрать из бэклога персистентность тем)
- Футер: заменить «без фреймворков» на «Vue 3 · TypeScript · один вечер и немного любви» или аналогичное

## Порядок работы

1. Скаффолд Vite + Vue + TS, перенос глобальных стилей и переменных
2. Данные в `data/`, типы
3. Обычный режим по секциям (сверять с эталоном визуально на 1280px и 375px)
4. Загрузчик и переключение режимов
5. Терминал: каркас → реестр команд → пасхалки → темы с persistence → matrix
6. Проверки из чек-листа ниже, README, обновление CLAUDE.md

Коммиты — по шагам выше, осмысленными сообщениями (репозиторий смотрят люди).

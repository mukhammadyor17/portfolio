# CLAUDE.md — Портфолио turskhanov.dev

Контекст проекта для Claude Code. Прочитай этот файл перед любыми изменениями.

## Что это

Персональный сайт-портфолио фронтенд-разработчика (Mukhammadyor Turskhanov) с двумя режимами интерфейса:

1. **Обычный режим** — светлый, в стиле Apple/iOS: крупная типографика, бенто-сетка, минимализм.
2. **Terminal mode** — полноэкранный эмулятор командной строки с командами, темами и пасхалками.

Ключевая идея: «снаружи глянец, внутри Unix». В светлом режиме нет терминальных намёков, кроме двух точек входа (кнопка в шапке и тёмная бенто-карточка). Контраст между режимами — намеренный.

## Структура

Один файл: `index.html` (для деплоя переименован в `portfolio.html`).
Всё внутри: HTML + CSS в `<style>` + JS в `<script>` перед `</body>`.
Внешние зависимости — только Google Fonts (Inter, Space Grotesk, JetBrains Mono).
Никаких фреймворков и сборки — это осознанное решение, упомянутое в футере.

Рядом должен лежать `resume.pdf` — на него ведут ссылки скачивания.

### Порядок блоков в файле

1. `<style>`: CSS-переменные → обычный режим → CRT-переход → терминал → загрузочный экран
2. `#loader` — загрузочный экран
3. `#site` — обычный режим (header, hero, projects, skills, contact, footer)
4. `#terminal` — терминал (term-head, #term-body, .term-chips, .prompt-row)
5. `<script>` — вся логика в одном IIFE

|---|---|---|
| `--green` | `#0F766E` | Акцент светлого режима (связан с терминалом) |
| `--term-bg` | `#101413` | Фон терминала (меняется темами) |
| `--term-green` | `#4ADE80` | Основной цвет терминала (меняется темами) |
| `--term-amber` | `#FBBF24` | Жёлтый акцент терминала (меняется темами) |
| `--term-text` | `#D7DDDA` | Текст терминала (меняется темами) |
| `--term-dim` | `#8B9490` | Приглушённый текст терминала (меняется темами) |

Светлый режим дополнительно использует прямые значения в духе Apple:
фон `#F5F5F7`, текст `#1D1D1F`, вторичный `#6E6E73`, оранжевый прогресса `#FF9F0A`.

### Типографика

- Основной шрифт: **Inter**, заголовки с отрицательным трекингом (−0.02…−0.035em).
- Хиро: `clamp(44px, 8.5vw, 84px)`, вес 700.
- Заголовки секций в манере Apple: жирная часть чёрная + серое продолжение
  (`Проекты. <span>Сделаны руками.</span>`).
- Моноширинный **JetBrains Mono** — только в терминале, загрузчике,
  кнопке terminal и карточке term-card. В остальном светлом режиме его быть не должно.

### Бенто-сетка

- `.bento` — 6-колоночный grid, gap 16px.
- Карточки: `.b-card` + класс ширины `.b-2` / `.b-3` / `.b-4` / `.b-6`.
- На экранах < 760px все карточки становятся во всю ширину.
- Скругление 24px, при ховере `scale(1.015)` + мягкая тень.
- Внутри: `.kicker` (маленький зелёный заголовок капсом) → `h3` → `p` → опционально `.tags`.

## Анимации

| Анимация | Где | Как устроена |
|---|---|---|
| Загрузочный экран | `#loader` | Печать домена посимвольно → строки инфо по очереди → CRT-off → `remove()` |
| Печатающаяся машинка | хиро, `#typed` | Массив `phrases`, печать/стирание по кругу |
| Появление секций | `.reveal` → `.on` | IntersectionObserver, threshold 0.2 |
| Прогресс-бары | `.bar i[data-w]` | Ширина проставляется при появлении секции |
| Теги проектов | `.tag` | Каскад с задержками nth-child при `.on` |
| CRT-переход | `.crt-off` / `.crt-on` | Схлопывание экрана как у ЭЛТ-телевизора, ~450мс |
| Тряска | `.shake` | Для `rm -rf` |
| Кольцо прогресса | `.b-learn svg` | stroke-dasharray/dashoffset, статичное |

**Важно:** все анимации уважают `prefers-reduced-motion: reduce` — загрузчик пропускается, машинка печатает одну фразу, matrix не запускается. Любая новая анимация обязана проверять `reduceMotion`.

## Терминал

### Архитектура

- Объект `commands` — имя команды → функция `(arg, raw)`, где `arg` — первый аргумент, `raw` — вся строка.
- `run(raw)` — парсит ввод, пишет строку с промптом, вызывает команду или `command not found`.
- `print(html, cls)` — одна строка вывода; `printLines(lines, done)` — построчная печать с задержкой 60мс.
- `esc(s)` — экранирование пользовательского ввода. **Всегда** применять к тому, что ввёл посетитель.
- `cmdNames` — пересчитывается после добавления команд, используется для Tab-автодополнения.
- История: стрелки вверх/вниз; Tab — автодополнение; клик по фону — фокус в инпут.
- На мобильных (< 640px) показываются чипы-кнопки с базовыми командами (`#chips`).

### Команды

Контентные: `help`, `about`, `projects [tracker|booking]`, `skills`, `contact`, `neofetch`.
Файловая система (фейковая): `ls [-a] [projects]`, `cat <файл>`, `pwd`.
Утилиты: `theme [имя]`, `clear`, `exit`, `date`, `echo`, `history`.

### Пасхалки (7 штук)

| Команда | Реакция |
|---|---|
| `sudo hire-me` | «Permission granted», ссылка на резюме |
| `rm -rf /` | Тряска экрана + «Nice try :)» |
| `ls -a` → `cat .secret` | Скрытый файл, «уровень любопытства: senior» + email |
| `whoami` | «тот, кого вы ищете в команду» |
| `git log` | Карьера в виде истории коммитов (2021→2026) |
| `coffee` / `make coffee` | Error 418: I'm a teapot (RFC 2324) |
| `matrix` | Canvas-дождь ~4 сек в цвете текущей темы → «Wake up, Neo…» |

Правило: не раскрывать пасхалки в `help` полностью — там только намёк.

### Темы

Объект `themes`: classic (дефолт), dracula, catppuccin, github, gruvbox, everforest.
Каждая тема задаёт 5 переменных: `bg`, `green`, `amber`, `text`, `dim`.
`applyTheme(name)` пишет их в `document.documentElement.style`.
Тема **не сохраняется** между перезагрузками (нет localStorage) — кандидат на доработку.

## Соглашения

- Весь пользовательский текст — на русском; команды и вывод в стиле Unix — на английском там, где это аутентично (`command not found`, `Permission granted`).
- Новая команда терминала: добавить в объект `commands` **до** строки `cmdNames = Object.keys(commands)` (вторая, после блока тем), при необходимости упомянуть в `help`.
- Новая карточка бенто: `.b-card` + класс ширины + `.reveal`; следить, чтобы ряды складывались в 6 колонок.
- Не добавлять localStorage/sessionStorage без явного запроса владельца.
- Не добавлять зависимости и сборщики — сайт принципиально один файл.
- Проверка после правок: открыть файл в браузере, прогнать `help`, `theme dracula`, `matrix`, переключение режимов туда-обратно, вид на ширине 375px.

## Известные ограничения / бэклог

- Тема терминала и режим не переживают перезагрузку страницы (нет персистентности).
- `resume.pdf` — файла пока нет, ссылки ведут в никуда.
- Контакты и ссылки на GitHub — заглушки.
- Домен: планируется `turskhanov.dev` (проверить свободность и точное написание).
- Возможные фичи: показывать загрузчик только при первом визите, звуки в терминале (с mute), команда `cowsay`.
